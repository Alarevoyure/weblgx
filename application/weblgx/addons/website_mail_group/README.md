# Listes de diffusion

Listes de diffusion du site, isolées par site (mode SaaS).

## Multi-site

Chaque liste appartient à un `website_id`. Configuration → Listes de diffusion n'affiche que le site de la société active. Une liste sans site n'est visible sur aucun site. Les règles de modération suivent la liste. Le domaine de messagerie ne propose que les domaines de la société du site.
