# Forum

Questions et réponses du site, isolées par site (mode SaaS).

## Multi-site

Chaque forum appartient à un `website_id`. Configuration → Forum → Forums, les étiquettes et les messages n'affichent que le site de la société active. Un forum sans site n'est visible sur aucun site.

Les motifs de clôture, les rangs et les badges restent communs.
